# Flow · Calm 版 — 即梦（Jimeng）主视觉提示词

> 用途：生成 Calm 极简 + Bento 版的 AIGC 主视觉 / 空状态插画。
> 方向：**抽象自然形态**（有机色块、流动曲线、柔和光晕），**不出现真人、不出现人脸**。
> 使用方式：复制提示词到即梦 → 选比例 → 生成 → 挑选 → 替换 `kv/key-visual.png`。

---

## 一、主视觉（Hero Key Visual）

- **比例**：16:10（或 3:2）　**模型**：即梦图片 2.1　**精细度**：高
- **提示词**：
```
抽象极简风格主视觉，柔和的有机色块与流动曲线，鼠尾草绿、暖沙色、雾蓝、米白，
低饱和自然色调，大量留白，柔和光晕，磨砂玻璃质感，平静治愈，
苹果官网式极简排版，无文字，无人物，无脸，高级感
```
- **负向词**：人物、人脸、写实、复杂、噪点、水印、文字、logo

---

## 二、空状态 / 卡片插画（Bento 卡片配图）

- **比例**：1:1　**模型**：即梦图片 2.1
- **提示词**：
```
极简抽象插画，柔和圆形色块与一条流动曲线，鼠尾草绿与暖沙配色，
磨砂质感，治愈平静，大量留白，苹果设计风格，无文字，无人物
```

---

## 三、专注氛围图（计时页背景）

- **比例**：9:16　**模型**：即梦图片 2.1
- **提示词**：
```
柔和模糊的抽象渐变背景，鼠尾草绿过渡到雾蓝与米白，
柔光晕染，颗粒质感，极简平静，无任何元素与文字，手机壁纸风格
```

---

## 四、替换位置

| 素材 | 替换到 |
|---|---|
| 主视觉 16:10 | `kv/key-visual.png` |
| 空状态 1:1 | Bento 卡片 / 空状态 |
