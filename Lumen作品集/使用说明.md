# 光合 Lumen 作品集 · 使用说明

## 交付内容

本项目最终只交付「光合 Lumen」的 UI/UX 作品集呈现，不包含真实 App、后端、传感器、语音识别、生成模型或数据持久化。

- `index.html`：完整作品集案例；
- `preview.png`：作品集整页预览；
- `preview-hero.png`：首屏预览；
- `screens/`：12 张核心手机界面；
- `diagrams/`：5 张研究、AI 与流程图表；
- `kv/`：项目主视觉；
- `motion/`：呼吸与夜行公交动效演示；
- `src/`、`diagrams/src/`：界面和图表的可编辑 HTML 源文件。

---

## 运行环境

- Node.js 24；
- Google Chrome：`C:\Program Files\Google\Chrome\Application\chrome.exe`；
- Playwright：`C:/Users/anyuxin/.cache/codex-runtimes/codex-primary-runtime/dependencies/node/node_modules/playwright`。

项目没有外部 npm 依赖，安装包仅用于命令入口。若系统没有 `npm`，直接运行下面的 Node 命令。

---

## 重新生成素材

在当前目录运行：

```powershell
node render.js
```

会重新生成：

- 12 张 `screens/*.png`；
- 5 张 `diagrams/*.png`；
- `kv/key-visual.png`；
- `motion/breath-poster.png`；
- `motion/night-bus-poster.png`；
- 对应的可编辑 HTML 源文件。

---

## 校验与导出预览

```powershell
node scripts/validate.js
```

会检查：

- 所有本地图片与 iframe 目标存在；
- 所有图片都有 `alt`；
- 所有锚点都有对应章节；
- 没有远程 URL；
- 1440 × 900 与 390 × 844 下没有横向溢出；
- 必需章节可见；
- 导出 `preview-hero.png` 和 `preview.png`。

## AIGC 披露

- 主视觉、梦境插画和动效方向可使用 Midjourney、即梦 AI 等工具辅助生成；
- 最终光源、构图、品牌节奏和界面文字由人工统一；
- 作品集不把工具数量当作设计成果；
- 产品内的 Curator、Listener、Dreamweaver 属于产品设计概念，不代表已实现真实 AI 服务。

---

## 范围声明

本项目不包含：

- 可点击原型；
- 真实语音识别或 TTS；
- 真实生成模型；
- 传感器或可穿戴设备接入；
- 后端、账号、数据库；
- 可用性测试数据、睡眠改善结论或医疗效果承诺。
